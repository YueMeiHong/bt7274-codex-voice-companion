# Changelog

## 0.7.1 — unpublished release candidate

- Native settings in Simplified Chinese, English and Japanese.
- Local Chinese BT synthesis and a separate English Piper BT model.
- Per-chat speech settings, microphone drafts, explicit sends and optional summaries.
- Separate DeepSeek, OpenAI-compatible and Ollama connection profiles.
- Local HTTP authentication, bounded requests, verified model assets and private event logs.
- AGPL-3.0-only for project contributions, with upstream notices retained.
- Complete Git marketplace package, first-install status and bundled setup skill.

No Japanese voice is included. Native settings refresh on open/save; the release
does not promise live refresh of an already-open settings page.
