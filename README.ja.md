## インストール

Windows、Python 3.12、Codex デスクトップと CLI、Git、Git LFS が必要です。完全なソースを取得し、以下を実行します。

```powershell
.\Setup-Models.ps1 -Download
.\Install-BT.ps1 -Install -RequireModels
.\Setup-English-BT.ps1
```

最後のコマンドは英語音声を使う場合に実行します。モデルと依存パッケージの初回取得にはネット接続が必要です。中国語と英語の合成・音声認識はローカルで動作します。ソースの保存先を移動・削除しないでください。CPU 版はインストーラーに `-TorchDevice cpu` を指定します。

## 設定

Codex → プラグイン → BT-7274 → 管理から、設定画面の言語を「日本語」に変更します。ブラウザーや埋め込み Web ページは使用しません。

- 設定画面は簡体字中国語・英語・日本語に対応します。
- 音声は中国語と英語に対応し、それぞれ独立した BT モデルを使用します。日本語音声はありません。
- 任意の BT 風要約は音声の言語に従います。設定画面の言語には影響されません。
- DeepSeek・OpenAI・OpenAI 互換・Ollama の接続先、API キー、モデルをプロバイダーごとに保存します。キーは使用者の PC の `config/providers.json` に保存し、Level 1 の `.env` は読み取りません。
- 要約は初期状態では無効です。有効にすると最終回答を選択したプロバイダーに送信します。ローカル Ollama は空のキーで使用できます。
- ピン留め・最近の会話一覧から対象を選択し、その会話で BT を有効にします。各項目は共通設定または会話専用の値を選択でき、音量は数値で入力します。

## マイクと制限

マイクは初期状態では無効です。会話を選択して有効にし、双方向音声モードにしてからマイクを有効にします。自動送信を無効にすると文字起こしの下書きを確認・編集できます。対象の会話を変更すると古い音声キューを破棄します。

現在の Codex 設定ページでは、開いたままのリアルタイム更新は確認できていません。設定を開き直すか保存すると一覧を再取得します。実機のマイク・音声出力と別 PC の新規インストールは引き続き検証が必要です。

英語音声は DJMalachite のコミュニティ製 Piper BT モデル、中国語は既存の中国語 BT モデルです。モデルは ZIP に同梱しません。由来・ライセンスの注意点は `MODEL-SETUP.md` と `ENGLISH-VOICE.md` を参照してください。ゲーム公式のプラグインではありません。

停止は `Stop-BT.cmd`、ソース ZIP の作成は `Build-Release.ps1` です。API キー、会話設定、録音、環境、モデルは配布 ZIP から除外されます。GitHub や公式ディレクトリへの公開はまだ行っていません。
